#Uso del Programa
Para realizar uso del programa correctamente, el mismo hace uso de las siguientes variables de entorno:

- DBA_LAB_URL: esta variable debe contener la url a través de la cual se hace uso de la API. 
- DBA_TOKEN: esta variable de contener el token adecuado para poder realizar uso de la API a través del programa.
- DBA_CHALLENGE_ID: esta variable debe ser cambiada en función del challenge a ejecutar. El funcionamiento del programa es dependiente de la modificación de esta variable.
