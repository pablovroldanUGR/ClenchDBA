# ClenchDBA
Equipo de clenches para asignatura DBA

## Cosas Importantes para las ejecuciones
- En Ubuntu, para crear variables de entorno del sistema, se asignan en el archivo /etc/environment. Para utilizarlas desde una terminal concreta, se usa el comando set /etc/environment.
