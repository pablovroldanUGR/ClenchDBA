# Guía de ejecución de la práctica 2 (equipo 202)
## Dependencias
Bibliotecas necesarias para la ejecución del proyecto:
1. JADE (asumimos que el profesor la tiene ya configurada).
2. GSON para parsear json que devuelve la API DBA_LAB (necesaria para el módulo de conexión a la API).

La bibilioteca GSON debe añadirse al proyecto de NetBeans para poder ejecutar el programa.

## Variables de entorno
Antes de ejecutar el programa, asegúrate de haber asignado las variables de entorno DBA_LAB_URL y DBA_TOKEN (necesarias para el módulo de conexión de la API).

## Archivos java
Todos los archivos de java sin compilar están en la carpeta src.
